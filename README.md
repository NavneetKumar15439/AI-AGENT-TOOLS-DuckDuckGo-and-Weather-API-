 Weather AI Agent

A basic AI Agent built using **Google Gemini, LangChain, DuckDuckGo Search, and OpenWeather API**.

The agent uses **Gemini 3.6 Flash** as its LLM and can decide which tool to use based on the user's question.

*  **DuckDuckGo Tool** — searches the internet for information.
*  **Weather Tool** — fetches current weather using OpenWeather API.
*  **LangChain Agent** — connects the LLM with the available tools.

The project demonstrates how an LLM can use external tools to retrieve real-time information and generate a final response.
